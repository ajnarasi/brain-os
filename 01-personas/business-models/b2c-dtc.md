# Business Model: B2C / D2C

Selling directly to end consumers. Card-present POS, e-commerce, or omnichannel retail.

## Characteristic pattern
- High transaction volume, low ticket size (usually)
- Fraud + chargeback focus
- Conversion optimization focus
- Returns handling

## Brain-relevant data sources
POS txns, e-com orders, returns, fraud tool, customer-facing email

## Memory schema
Merchant → Store/Site → Terminal/Session → Transaction → (Customer if available)

## Brain capabilities that matter most
- Fraud tuning
- Approval rate optimization
- Returns narrative
- Checkout funnel analytics

## Typical size
All sizes. The "default" business model.
