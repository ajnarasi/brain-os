# Business Model: Omnichannel / Unified Commerce

Card-present and card-not-present linked through shared identity, inventory, and order systems. BOPIS, ship-from-store, tokenized loyalty, unified returns.

## Characteristic pattern
- Customer identity persists across channels
- Inventory is shared (BOPIS requires real-time inventory accuracy)
- Payment tokens interoperate (pay online, return in-store)
- Cross-channel analytics needed

## Brain-relevant data sources
Unified order system (OMS), tokenization vault, loyalty system, inventory system, POS, e-com

## Memory schema
Merchant → Customer (persistent token) → Order → Fulfillment (multi-channel) → Return

## Brain capabilities that matter most
- Channel reconciliation (when does an online order become an in-store pickup?)
- Token interoperability
- Cross-channel fraud (an online purchase and in-store return on the same day is a red flag)
- BOPIS ops

## Typical size
Mid-market to enterprise. Requires real tech investment to do properly.

## Overlap
Omnichannel merchants almost always also run B2C/D2C simultaneously. A mid-market fashion brand is both.
